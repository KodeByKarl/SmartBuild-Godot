# Module 2 model drops

Place Sketchfab packages in the **organized** folders:

`res://assets/models/module_2/<part_name>/`

Example:
- `assets/models/module_2/modem/scene.gltf` (+ `scene.bin`, `textures/`)
- `assets/models/module_2/router/scene.gltf` (+ `scene.bin`, `textures/`)

Router and modem glTFs from this folder were copied there and wired in `module_content_registry.gd`.
